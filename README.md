# 🏝️ ClickCraft

Um jogo de farm clicker baseado em ilhas, desenvolvido em HTML, CSS e JavaScript puro.

## 🎮 Sobre o jogo

Em ClickCraft você começa em uma ilha inicial e vai coletando recursos, fabricando ferramentas e expandindo seu território comprando novas ilhas. O jogo é jogado direto no navegador, sem instalação.

## ⚙️ Como jogar

- Clique na **árvore** para coletar madeira
- Clique no **Sell** para vender madeira e ganhar moedas (Ctrl + clique vende tudo de uma vez)
- Clique no **Shop** para comprar blueprints de ferramentas
- Clique no **Crafter** para fabricar as ferramentas com os recursos coletados
- Ferramentas melhoram sua produção e desbloqueiam novos recursos

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (Vanilla)
